# Plain CNN (VGG8B) on CIFAR-10 / CIFAR-100: backprop vs ours (batch cnn01)

- author: Deyvik Bhan
- dates: 2026-11-24
- code: `ng/deyvik-cnn` (new `cnn/` package, `gametorch/`, `scripts/run_cnn.py`)
- learning rates: batch cnn00 screen (CIFAR-10, width 0.5, 20 epochs, seed 1):
  backprop Adam 3e-3 (best of Adam 3e-4 / 1e-3 / 3e-3 / 1e-2, SGD 0.01 / 0.05);
  ours SGD 0.02, momentum 0.9 (best of 0.01 / 0.02 / 0.05)

## Why

The spiking MLP tops out near 50% on CIFAR-10, so the architecture, not the
rule, limits the CIFAR numbers. This batch takes a standard published CNN,
VGG8B (Nokland & Eidnes 2019), and trains it two ways: with backprop, and with
our rule replacing `loss.backward()` (no autograd anywhere; a guard counts
autograd calls and must read 0).

## What was built

- `cnn/model.py`: VGG8B as an ordinary `nn.Sequential` (conv128-conv256-pool-
  conv256-conv512-pool-conv512-pool-conv512-pool-fc1024-fc; 3x3 conv + BatchNorm
  + ReLU; no dropout), any dataset shape, width multiplier.
- `cnn/local_rule.py`: our rule for conv nets. dW = signal x local derivative x
  input for every layer; the signal goes down one layer at a time through
  learned feedback weights B (layerwise Kolen-Pollack, conv feedback is a
  transposed conv with B). BatchNorm, ReLU and max-pool pass the signal with
  their own local quantities. Controls: direct random feedback to every ReLU;
  frozen random conv layers (only the fc head learns).
- `gametorch/`: the same rule as a drop-in `.backward()`: the model's own
  forward runs unchanged, forward hooks record what each layer's rule needs,
  `loss.backward()` runs our rule, Kolen-Pollack runs after `optimizer.step()`
  through optimizer hooks.
- Tests (`tests/test_cnn_local_rule.py`, `tests/test_gametorch.py`): with B = W
  the rule equals backprop's gradients for every layer (float64), also with the
  energy term; the gametorch path equals the recorded-forward path; 0 autograd
  calls; KP shrinks B - W by (1 - d) per step.

## Setup

VGG8B full width (8.9M parameters), 50 epochs, batch 128, cosine schedule,
per-channel normalization, random crop + flip, seeds 1-5, RTX 5080.

```bash
python scripts/run_cnn.py --arm bp --optimizer adam --lr 3e-3 --dataset <ds> --seed <s>
python scripts/run_cnn.py --arm ng --optimizer sgd --lr 0.02 --dataset <ds> --seed <s>
# controls
python scripts/run_cnn.py --arm ng --optimizer sgd --lr 0.02 --path direct ...
python scripts/run_cnn.py --arm ng --optimizer sgd --lr 0.02 --trainable fc ...
```

## Results (5 seeds, mean +- std)

| | CIFAR-10 test | CIFAR-100 test |
|---|---|---|
| backprop | 92.49 +- 0.22 | 69.26 +- 0.34 |
| ours (layerwise KP) | 92.44 +- 0.19 | 72.84 +- 0.33 |
| control: direct random feedback | 78.47 +- 0.34 | 48.33 +- 0.29 |
| control: frozen random conv | 69.67 +- 0.46 | 42.19 +- 0.12 |

CIFAR-10, ours vs backprop (CIFAR-100 shows the same pattern):

| | ours | backprop | |
|---|---|---|---|
| training ms / step | 29.15 | 28.59 | +2% (loss) |
| GPU energy / step (NVML) | 8.32 J | 8.25 J | tie |
| peak training memory | 1049 MiB | 1259 MiB | -17% (win) |
| nonzero network MACs / test image | 567 M | 386 M | +47% (loss) |

Feedback alignment cos(B, W) at the end: 0.67-0.99 per layer.

## Reading

- Accuracy: tie on CIFAR-10. The CIFAR-100 lead is **not yet trusted**:
  1. the KP step also shrinks the weights by 1e-4 per step (weight decay),
     backprop had none;
  2. backprop used Adam, ours SGD;
  3. backprop's Adam rate is 6-10x published values, and published backprop
     VGG8B reaches 94.0 / 73.8 (400 epochs, dropout).
- The controls show the conv layers really learn under our rule (+23 / +31
  points over frozen) and that layer-by-layer feedback matters (+14 / +25 over
  direct feedback).
- Energy is **not a win yet**: per-step energy ties, the step is 2% slower and
  our trained network is 47% denser at inference. Adam is known to produce
  sparser BN-ReLU features than SGD, so part of the density gap may be the
  optimizer.
- The memory saving comes from not keeping autograd's saved tensors, not from
  the algorithm.
